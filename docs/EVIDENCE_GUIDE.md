# Building a stronger research submission

For each experimental project, the most useful next artifact is a short, attributable record of what was actually done:

1. State the question or engineering objective.
2. Describe your personal contribution and your collaborators' roles.
3. Include the actual method: materials, apparatus, settings, calibration and analysis.
4. Attach original data with units and a description of how it was collected.
5. Explain one result, its uncertainty and at least one limitation.
6. Include images, a report or code only when you have permission to share it.

For the PUF, prioritize device images, repeated response measurements and the image-to-bit procedure. For the solar tracker, prioritize wiring, firmware and simultaneous fixed-versus-tracking measurements. For the motor controller, prioritize the schematic and timing/speed measurements.

For computational projects, explain the algorithm, show a reproducible input/output example and discuss limits. Keep a clear distinction between the original work and newer reference implementations. Be prepared to walk through any code linked in an application.

The generated example tests are software checks, not evidence that a laboratory device met a performance target.
