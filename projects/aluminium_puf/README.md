# Aluminium-mesh PUF

I worked on a physical unclonable function (PUF) project using aluminium mesh and glass. The fabrication steps in my project summary are spin coating, aluminium deposition, and photolithography. The project also explored authentication and the use of image analysis to study response randomness.

I have not uploaded the original device images, response measurements, fabrication notes, or image-analysis code. The previously stated “80% uniqueness” figure is not documented here because I do not have the measurement protocol and raw results in this repository.
