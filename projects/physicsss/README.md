# PHYSICSSS

[Play the game](https://gaurangagarwal351.github.io/PHYSICSSS/) or inspect the [source](../../index.html).

PHYSICSSS is a browser platform game written in JavaScript and HTML Canvas. It has changing gravity and friction, a story mode, touch controls, and a Firebase-based multiplayer mode. The game source is at the repository root, mainly in `index.html` with companion JavaScript files.

The mechanics are designed for gameplay. They are not calibrated physics measurements or a scientific simulation. Multiplayer requires network access and a working Firebase database configuration.
